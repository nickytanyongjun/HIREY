# HIREY
HIREY—our AI-powered sourcing hub designed to act as an immediate force multiplier for recruitment workflows.

SYSTEM REQUIREMENTS:
OS: Windows
Python: version 3.11 or 3.12
Code Editor: Visual Studio Code

This is how you use HIREY, start by downloading the HIREY file. Inside the file there are two more file name static and templates, !DONT TOUCH THE TWO FILES(static & templates)! as it is the frontend to your website. Next, the app.py is the main file inside line number 16 replace YOUR_CHUTES_API_KEY with your actual chutes api key. After that, open your in Visual Studio Code terminal and paste these into it "pip install flask requests pypdf".

HOW TO RUN:
After you replace YOUR_CHUTES_API_KEY with your actual chutes api key you can run the website by just running the app.py file or pressing 'F5' while in the file in the terminal there's a localhost link "eg: http://167.0.0.1:9999" by copying it and pasting it into your disire webbrowser there you have it HIREY!!
